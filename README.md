# Корни-сокровища — готовый сайт

Это комплект сайта с оригинальной игрой. Сборка и установка не нужны.

## GitHub Pages

1. Распакуйте архив.
2. В репозитории arenissa/korni_klad откройте Add file → Upload files.
3. Загрузите содержимое папки korni_klad: index.html, папку assets целиком и остальные файлы. Важно: в корне репозитория должен лежать index.html, а не ещё одна папка korni_klad.
4. Сохраните изменения (Commit changes).
5. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).
6. После завершения публикации откройте https://arenissa.github.io/korni_klad/ и обновите страницу.

Папка assets обязательна: в ней стили, шрифты, код игры и база слов.
Она переименована из _next, все ссылки исправлены. Обычное имя также предотвращает исключение папки обработчиком Jekyll. Файл .nojekyll добавлен как дополнительная настройка статической публикации.

## Другой хостинг

Загрузите index.html, assets и остальные файлы в одну папку сайта. Сайт использует относительные пути и подходит для вложенной папки.

## Локальный просмотр

Откройте index.html в браузере. Сохраните папку assets рядом с ним.
