# Публикация игры «Корни-сокровища»

Эта папка — **готовый статический сайт**. Главный файл — `index.html`.
Никакой установки и базы данных не нужно. Игра даже работает **без интернета**:
достаточно открыть `index.html` двойным кликом.

## Вариант 1. Netlify Drop — самый быстрый (2 минуты)

1. Откройте https://app.netlify.com/drop
2. Перетащите эту папку целиком в окно браузера.
3. Через несколько секунд игра получит публичную ссылку вида `https://имя.netlify.app`.
4. Ссылку можно отправить ученикам или повесить на стенд класса.

## Вариант 2. GitHub Pages (бесплатно, навсегда)

Сборка использует относительные пути, поэтому работает даже во **вложенной папке**
(`имя-пользователя.github.io/имя-репозитория/`):

1. Создайте репозиторий на GitHub (например, `korni-sokrovischa`).
2. Загрузите в него **содержимое** этой папки (файл `index.html` должен оказаться в корне репозитория).
3. В настройках репозитория: **Settings → Pages → Source: Deploy from branch → main**.
4. Через 1–2 минуты игра откроется по адресу `https://имя.github.io/korni-sokrovischa/`.

## Вариант 3. Школьный сервер или любой хостинг

Скопируйте все файлы из этой папки в корневую папку сайта
(`public_html`, `htdocs` и т. п.). Игра откроется по адресу вашего сайта.

## Вариант 4. Vercel (если хотите собирать из исходников)

Загрузите исходный проект (см. архив исходников) на GitHub и импортируйте
репозиторий на https://vercel.com/new — Vercel соберёт всё автоматически.

## Советы для класса

- **QR-код**: сгенерируйте QR-код по ссылке (например, на qrcode-tec.com) — ученики
  наводят камеру телефона и сразу попадают в игру.
- **«Экран-класс»**: командный режим удобнее вести с проектора.
- **Один сайт — много игроков**: прогресс хранится локально в браузере игрока,
  поэтому одна ссылка подходит всем, а результаты не смешиваются.
